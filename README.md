# B站点播歌曲机器人
## 一、项目简介

本项目是一个独立运行的 B 站直播间弹幕点歌机器人，通过监听直播间弹幕，识别观众的点歌指令，并调用本机运行的洛雪音乐进行歌曲搜索与播放。

## 二、功能说明

- **弹幕点歌：** 支持按歌曲名称点歌，也支持指定歌手。
- **管理员切歌：** 只有配置的管理员可以执行切换下一首歌曲的操作。
- **粉丝牌权限：** 可以在 `room_config.txt` 中配置是否要求观众拥有当前直播间的粉丝勋章。
- **点歌冷却：** 普通观众每次点歌后需要等待 10 秒；管理员不受冷却限制。
- **队列管理：** 最多排队 30 首歌曲，禁止重复歌曲进入队列。
- **自动播放：** 当前歌曲播放结束后，自动播放队列中的下一首。
- **Cookie 登录：** 使用 B 站 Cookie 进行需要登录态的权限验证。

## 三、项目文件结构

```
/
├── main.py             # 主程序：弹幕监听、权限验证、点歌与播放控制
├── room_config.txt     # 配置文件：直播间、管理员及点歌权限
├── bili_cookie.txt     # B站 Cookie
├── uid.txt             # 管理员或相关用户 UID 配置（按程序实际读取逻辑）
├─ queue_panel.html         # 本地队列管理页面
├─ display_panel.html       # OBS 浏览器显示页面
└── README.md           # 项目说明文档
```

说明：

- `main.py`：程序的主要逻辑。
- `room_config.txt`：用于设置直播间及点歌权限。
- `bili_cookie.txt`：保存 B 站登录 Cookie，请勿泄露。
- `uid.txt`：用户 UID 配置文件，具体用途以当前版本代码的读取逻辑为准。

## 四、运行环境

运行前需要准备：

1. Windows 电脑。。
2. 洛雪音乐（LX Music）v2.12.6。
3. 洛雪音乐本机 API 服务，默认地址为 `127.0.0.1:23330`。
4. 可正常访问 B 站直播弹幕服务的网络环境。
5. 有效的 B 站 Cookie（用于需要登录态的粉丝牌权限验证）。

## 五、配置说明

### 1. 配置直播间及点歌权限

编辑 `room_config.txt`，按照当前程序支持的字段配置直播间 ID、管理员 UID，以及是否启用粉丝牌限制。

粉丝牌权限的设计规则：

- 启用粉丝牌要求时，观众必须满足配置规定的粉丝牌条件，才允许点歌。
- 关闭粉丝牌要求时，不因缺少粉丝牌而拒绝点歌。

### 2. 配置 B 站 Cookie

将有效的 B 站 Cookie 按照程序要求保存到：

```
bili_cookie.txt
```

请注意：

- Cookie 属于登录凭据，不要发给其他人。
- 不要将包含有效 Cookie 的配置文件上传到公开仓库。
- Cookie 过期后，登录态验证可能失败，需要更新 Cookie，扫码登录后自动更新bili_cookie.txt。

### 3. 配置 UID

管理员身份应以程序实际使用的管理员配置为准。

### 4. 配置洛雪音乐 API

启动洛雪音乐 v2.12.6，并确保本机 API 服务正常运行。

默认 API 地址：

```
http://127.0.0.1:23330
```

如果洛雪音乐没有启动、API 服务未开启或端口不一致，机器人可能无法搜索歌曲或控制播放。

## 六、弹幕指令

### 1. 点播歌曲

按歌曲名点歌：

```
点歌 歌名
```

指定歌曲和歌手：

```
点歌 歌名 歌手
```

例如：

```
点歌 晴天
点歌 晴天 周杰伦
```

程序收到有效指令后，会根据当前实现调用洛雪音乐搜索歌曲，并将符合要求的歌曲加入待播放队列。

实际搜索结果取决于洛雪音乐配置的音乐来源及其可用性。

### 2. 切换下一首

切歌指令仅供管理员使用。普通观众不应拥有切歌权限。

## 七、点歌规则

| 项目             | 规则                      |
| ---------------- | ------------------------- |
| 普通观众点歌冷却 | 10 秒                     |
| 管理员点歌冷却   | 无                        |
| 最大待播放队列   | 30 首                     |
| 重复歌曲         | 禁止重复加入              |
| 播放结束         | 自动播放下一首            |
| 切歌权限         | 仅管理员                  |
| 粉丝牌限制       | 由 `room_config.txt` 控制 |
| 粉丝牌验证       | 需要时使用 B 站 Cookie    |

队列已满、歌曲重复、用户权限不符合要求或点歌处于冷却期间时，程序应按照当前版本的处理逻辑拒绝或提示相应操作。



## 八、注意事项

1. 不要将 `bili_cookie.txt` 或其他登录凭据公开。
2. 不要随意修改配置文件的字段名和格式。
3. 本文中的具体指令、配置字段和文件行为应以项目当前版本代码为准。
